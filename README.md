# Portfolio con IA

Este proyecto es un portfolio personal frontend potenciado con funcionalidades de Inteligencia Artificial. Su objetivo es mostrar trabajos, experiencia y permitir generar contenidos (descripciones, imágenes o texto) asistidos por modelos de IA para facilitar la actualización y personalización del contenido.

## Características principales
- Página de inicio con presentación breve, incluye un carrousel con vinculos a las secciones.
- Sección "Sobre mí" con experiencia y habilidades.
- Galería/Sección de proyectos con detalles y enlaces.
- Formulario de contacto.
- Funcionalidades con IA: generación automática de descripciones de proyectos, sugerencias de texto para el About, o generación de imágenes/art assets (según la integración usada).
- Diseño responsive y fácil de personalizar.
